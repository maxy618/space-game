# Procedural Universe

1. Define hierarchy and stable IDs; derive child seeds from stable parent identity, never array position.
2. Separate physical/synthetic parameters, game-scale compression, render coordinates and travel distance; document units.
3. Research population relationships and label evidence/uncertainty.
4. Generate/stream only the needed region; keep caches bounded.
5. Separate immutable base world from player discoveries/modifications.
6. Ensure request order does not alter generated chunks.
7. Test ranges, relationships, determinism, serialization and generator migration.
8. Keep fixed-seed showcase routes for QA.

Avoid global unseeded random calls, one seed for the entire save, loading all systems or fabricated science.
