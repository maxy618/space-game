# Performance Profiling

1. Profile dense systems, postFX, entry, clouds/weather, oceans, ecosystems and rover scenes.
2. Record hardware/browser/viewport/seed/tier/duration and frame-time distribution; distinguish CPU data from GPU estimates.
3. Track draw calls, particles, render targets, resolution, shader passes, memory and generation.
4. Optimize measured bottlenecks only.
5. Use LOD, adaptive resolution, pooling, bounded caches and simplified shaders where justified.
6. Confirm low tier preserves readability and core gameplay.
7. Repeat the same benchmark after changes.

Avoid empty-scene FPS claims, laptop-to-phone assumptions or disabling core gameplay for a number.
