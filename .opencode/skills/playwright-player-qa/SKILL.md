# Playwright Player Qa

1. Launch actual build and open via Playwright; capture console/page errors/network failures.
2. Use reproducible seed/routes.
3. Use real keyboard/mouse/pointer/touch input to move, steer, brake, select, interact, scan, land, drive or equip.
4. Test press/release, simultaneous input, pointercancel, focus loss, pause/resume, resize and reload.
5. Capture screenshots/video during meaningful states; inspect full view and close crops.
6. Fix and replay the same route.
7. Label evidence desktop browser, touch emulation, Android emulator or physical Android.

Acceptance: every gameplay task has input-driven evidence. A screenshot after load is not a playtest.
