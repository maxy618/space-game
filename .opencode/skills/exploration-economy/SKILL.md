# Exploration Economy

1. Define stable event types/keys for new system, planet, region, species, geology and phenomena.
2. Separate first discoveries from revisits/repeat scans.
3. Balance reward curves and sinks across different exploration styles; document early/mid/late examples.
4. Implement scanner, journal, concise feedback and saved progress.
5. Make reward handling idempotent across reloads and duplicate triggers.
6. Connect currency to ship/module purchases.
7. Play route: discover, earn, save/reload, revisit, buy; test exploit attempts.

Avoid unlimited repeated rewards, scattered hard-coded prices, empty currency sinks or menu-only discoveries.
