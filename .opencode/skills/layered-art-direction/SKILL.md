# Layered Art Direction

1. Start with silhouette, composition and value groups — not glow/noise.
2. Add coherent regional structure: continents, dunes, strata, cloud masses, nebula filaments, creature clusters and ship assemblies.
3. Define separate material response for rock, ice, ocean, cloud, dust, metal and organic surfaces.
4. Add fine detail only when visible at target zoom; preserve phone-size silhouette.
5. Establish palette/lighting per environment family; no hue-shift-only biomes.
6. Add parallax and secondary motion that communicates scale/material.
7. Review actual gameplay size and 2–4x crops; log/fix defects.
8. Draw all final interface icons as bespoke paths/geometry.

Audit shiny plastic, generic gradients, noise wallpaper, repetition, blur, excess bloom, weak silhouettes and fake UI clutter.
