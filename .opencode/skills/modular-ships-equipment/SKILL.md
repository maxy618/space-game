# Modular Ships Equipment

1. Define ship roles, handling, equipment slots, compatibility and unlocks in data.
2. Give hulls different silhouettes, not just palette swaps.
3. Define module anchors/orientation/z-order/compatibility.
4. Draw modules as attached parts with materials and active animation.
5. Connect to real behavior: thrust, scan, hover, cargo, protection, landing, etc.
6. Integrate purchase/equip/remove/save/load.
7. Fly same route with base and upgraded ship; compare silhouette and handling.

Avoid stat-only upgrades, floating UI badges as art, arbitrary compatibility or one dominant ship.
