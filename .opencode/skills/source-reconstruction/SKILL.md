# Source Reconstruction

1. Verify exact source revision, runtime pages, version differences, commit SHA, retrieval date and license.
2. Run the reference and exercise actions with Playwright; capture input, state, viewport and result.
3. Trace runtime behavior to source modules, data flow, coordinate conventions and update timing. Label observed/source-derived/inferred/unknown.
4. Port only code with verified compatible licensing; preserve copyright/LICENSE/NOTICE and mark modifications. Recreate behavior independently where provenance is unclear.
5. Compare the same route/seed/viewport in reference and recreation.
6. Add regression tests plus real Playwright input routes.

Avoid bulk copying without provenance, copying assets under a code license, screenshot-only assumptions or claims of exact parity without evidence.
