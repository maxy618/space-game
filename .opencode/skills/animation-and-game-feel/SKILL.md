# Animation And Game Feel

1. Define state changes and needed player cues: anticipation, action, impact, settle, exit.
2. Use consistent easing/timing; avoid unnecessary input-blocking animations.
3. Add secondary motion to ships, clouds, organisms, plants, rover, water and UI where it communicates material/force.
4. Tie sound to actual gameplay events with ambient layers and mix priority.
5. Make transitions interruptible/recoverable and respect reduced motion.
6. Play each event in context, not only in a preview.

Avoid random shake, uninterruptible cutscenes, generic clicks everywhere or obscured controls.
