# Visual quality standard

Target: authored, memorable layered 2D with coherent depth, not generic glossy 3D. Design macro silhouette/composition first; regional forms second; material response third; fine detail only at useful zoom; then parallax, animation, light and contextual optics.

Not final art: generic icon packs/emoji, shiny gradient spheres, identical noise shaders recolored per planet, random noise wallpaper, fake telemetry, arbitrary decorative hexagons, permanent chromatic aberration, bloom everywhere, cluttered HUD cards or uncredited stock/AI-looking assets.

Review at actual phone gameplay size and 2–4x crop: silhouette, values, palette, aliasing, banding, texture stretch, seams, repetition, LOD popping, compositing, overdraw, motion clarity and control visibility. Log defects, fix and recapture.
